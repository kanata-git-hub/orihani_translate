# 체스 해설 비교 시험

경로: `/app/chess-compare`. 기존 번역 기능과 별도 페이지/API이며 앱 소유자 로그인만 허용합니다.
서버의 기존 `OPENAI_API_KEY`, `GEMINI_API_KEY`를 사용합니다. 키 입력창이나 클라이언트 키 전송은 없습니다.
페이지를 열면 설정만 읽습니다. `API 인증 확인`은 모델 조회만 수행합니다. 유료 호출은 `비교 시작`으로 실행합니다.

## 비교 조건

- 고정된 12개 국면과 Stockfish 19 참조 자료. 모든 모델에 같은 프롬프트 SHA256.
- `gpt-5.6-terra`, `gpt-6-astra`, `gpt-6-sol`, `gpt-6-luna`, `gemini-3.8-flash`. API 키와 생성 방식은 기존 서버 연결을 재사용합니다.
- OpenAI는 동일한 low/medium/high 설정, 기본 medium. Gemini는 공급자 기본 추론 설정.
- 동일 출력 상한 4096토큰. OpenAI는 standard service, store=false.
- 순차 실행하고 국면·반복별 모델 순서를 교대합니다. 모델 자동 대체·자동 재시도 없음.
- 서버에서 요청 시작부터 전체 응답을 읽을 때까지 측정. 인증·Stockfish 준비·브라우저 왕복 제외.
- 추론 토큰을 포함한 실제 응답 사용량으로 비용을 추정합니다. 불명 사용량은 null입니다.
- OpenAI 캐시 쓰기량을 구분하지 못하는 경우 모든 비캐시 입력이 캐시 쓰기인 상한도 표시합니다.
- Gemini는 유료 standard 단가 기준. 무료 티어/실제 청구서와 다를 수 있습니다.
- 예산은 브라우저가 전체 작업의 보수적인 토큰 비용을 예약해서 확인합니다. 공급자 계정 전체의 과금 제한 기능은 아닙니다.
- 서버는 고정 프롬프트와 모델만 받고 요청별 토큰 상한, 소유자별 동시 1개, 인스턴스별 30분당 120회 제한을 적용합니다.

## 평가

자동 검사는 기물의 위치/색, 현재 보드의 공격/절대 핀, 추천수 및 분기 수순의 합법성을 확인합니다.
전략적 설명의 타당성·이해도를 자동 정확도 점수로 포장하지 않습니다. 결과에서 별도로 평가하고 JSON에 보관합니다.
12개 예비 국면이며 일반적인 체스 실력의 순위는 아닙니다. E1/E3는 정확한 테이블베이스의 무승부 판정을 우선합니다.

새 요청 시작 시 이전 시험 대신 마지막 시험만 소유자별 브라우저 저장소에 보관합니다.
중단 버튼은 진행 중인 응답과 사용량을 받은 후 다음 요청을 멈춥니다. 페이지를 닫으면 현재 호출을 취소하지만 공급자 과금 여부는 미확인일 수 있습니다.

## 체스판 시각화

- 각 해설 안에 강점·약점, 공격 방향, 추천수·진행 탭이 있습니다. 기존 브라우저에 저장된 해설에도 적용되며 다시 유료 생성할 필요가 없습니다.
- 강점·약점은 모델의 판단으로 명시하고 색과 기호를 함께 표시합니다. 같은 말이 강점과 약점일 수 있어 두 표식을 모두 표시합니다.
- 말을 누르면 공격 대상, 같은 편 보호, 상대의 공격을 현재 보드에서 계산합니다. 틀린 모델 공격 주장을 그대로 그리지 않습니다.
- 빈칸 공격 범위는 점, 기물 간 공격은 화살표, 같은 편 보호는 점선입니다. 나이트의 화살표는 꺾어서 그립니다.
- 기하학적 공격 범위와 합법 수는 별개입니다. 핀에 묶인 말의 공격 범위도 표시되지만, 진행 재생에서는 매 수의 합법성을 별도 확인합니다.
- 진행 중에는 시작 국면의 강점·약점 표식을 숨기며, 불법 수를 만나면 마지막 합법 위치에서 멈춥니다. 판을 뒤집으면 표식과 화살표도 함께 회전합니다.
- 비교의 프롬프트·국면·출력 상한은 그대로 유지합니다. API 인증 확인은 다섯 모델을 모두 조회할 수 있습니다.

## 실행/검증

```
npm ci
npm run lint
node --experimental-strip-types --test tests/chessComparison.test.ts
npm run build
```

테스트 응답은 오프라인 fixture입니다. 모델의 실제 체스 성능 측정이 아닙니다.
모델별 API 인증·생성 성공은 배포 후 소유자 계정으로 직접 확인해야 합니다.
